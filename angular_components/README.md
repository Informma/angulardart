# AngularDart Components Monorepo

This repository contains the **AngularDart Components** library — a community-maintained fork of Google's original [AngularDart](https://pub.dev/packages/angulardart) Material Design component library.

## Packages in this monorepo

### [angulardart_components]&nbsp;[![Pub Package](https://badgen.net/pub/v/angulardart_components?v=3.0.3)](https://pub.dev/packages/angulardart_components)

The main Material Design component library for AngularDart, published on pub.dev as `angulardart_components`.

- [API Reference](https://pub.dev/documentation/angulardart_components/latest/)
- [Source Code](https://github.com/flutterdocteur/angulardart/tree/main/angular_components/angular_components)

## Requirements

- Dart SDK >= 3.0.0
- AngularDart >= 9.0.0
